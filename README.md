# Барбершоп «Мафия» — сайт

Одностраничный сайт с онлайн-записью для барбершопа «Мафия» (Тюмень, ул. Широтная, 124).
Тёмная тема, каталог из 13 услуг, корзина, выбор мастера и времени, заявки в SQLite
и уведомления в Telegram.

## Стек

- **Next.js 15.5** (App Router) + React 19 + TypeScript
- **Tailwind CSS 4** — дизайн-токены в `app/globals.css`
- **SQLite** через встроенный `node:sqlite` (Node 22.5+/24, без нативных сборок)
- Шрифты `@fontsource/oswald` и `@fontsource/inter` — локально, без Google Fonts
- Отзывы и посты подтягиваются с 2ГИС, Яндекс Карт и из группы VK (`lib/social/*`)

## Быстрый старт

Нужен Node.js 22.5+ (проверено на 24.22.1).

```bash
npm install
cp .env.example .env.local   # Windows: copy .env.example .env.local
npm run dev
```

Откройте http://localhost:3000.

Продакшн-сборка:

```bash
npm run build
npm run start
```

База `data/mafia.db` создаётся автоматически при первой заявке. Каталог `data/`
должен быть доступен на запись.

| `SYNC_TOKEN` | Секрет для `POST /api/sync`; пусто — только с этой машины |
| `VK_TOKEN` | Сервисный ключ VK (необязательно, см. ниже) |
| `VK_GROUP` | Короткое имя группы VK |
| `TWOGIS_BRANCH_ID` / `YANDEX_ORG_ID` | id карточек, если их пересоздадут |
| `TWOGIS_REVIEWS_KEY` | Ключ отзывов 2ГИС, если старый перестанет работать |

### Как подключить Telegram

1. В Telegram: `@BotFather` → `/newbot` → имя и username → скопируйте токен.
2. Напишите боту любое сообщение (или добавьте бота в группу и напишите там).
3. Откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `chat.id`.
   У группы id отрицательный (`-100...`).
4. Заполните `.env.local`, перезапустите сервер.

Без токена сайт работает: заявка сохраняется в БД, а готовый текст уведомления
печатается в консоль сервера (`[telegram:fallback]`).

## Синхронизация с 2ГИС, Яндекс Картами и VK

Блок «Отзывы» и лента «Свежее из группы» обновляются сами:

| Площадка | Что берём | Как |
| --- | --- | --- |
| 2ГИС | рейтинг, число отзывов, тексты + ответы барбершопа | публичный endpoint отзывов 2gis.ru |
| Яндекс Карты | рейтинг, оценки, число отзывов, тексты | JSON из HTML карточки `/reviews/` |
| ВКонтакте | подписчики, последние посты | `wall.get` с ключом или виджет сообщества |

Один прогон — `POST /api/sync`, занимает 1–3 секунды. Данные кладутся в SQLite
(`social_reviews`, `social_posts`, `social_stats`, `social_sync`), а страница
пересобирается через `revalidatePath("/")`.

```bash
npm run sync          # обновить сейчас (POST /api/sync)
npm run sync:install  # задача планировщика: каждые 3 часа
```

- Доступ к endpoint'у: заголовок `x-sync-token` или `?token=`. Пока `SYNC_TOKEN`
  пуст, запросы принимаются только с этой же машины.
- Лог — `data/sync.log`. Состояние — `GET /api/sync` (источники, время, ошибки).
- Если площадка не ответила (капча Яндекса, смена ключа 2ГИС), на сайте остаются
  данные прошлого успешного прогона, а в лог пишется причина. Сайт не ломается.
- 2ГИС не даёт официального API отзывов, поэтому используется ключ веб-клиента.
  Если он сменится — возьмите актуальный и положите в `TWOGIS_REVIEWS_KEY`.
- VK работает и без ключа (виджет), но с сервисным ключом надёжнее:
  [dev.vk.com](https://dev.vk.com) → «Мои приложения» → приложение →
  «Сервисный ключ доступа» → `VK_TOKEN`.
- Виджет VK отдаёт `windows-1251`, Яндекс и 2ГИС — UTF-8. Адаптер читает байты и
  декодирует по `charset` из `Content-Type`; иначе посты VK приходили бы кракозябрами.
- Без ключа флаг «закреплено» не определяется: виджет ставит эту подпись в каждую
  карточку, поэтому посты считаются незакреплёнными (с `VK_TOKEN` флаг настоящий).
- Картинки постов идут через `/api/vk-image?u=…`: часть CDN ВК отдаёт файлы только
  с `Referer: https://vk.com/`. Прокси качает их с сервера, кэширует в
  `data/vk-images/` (30 дней) и разрешает только домены `userapi.com` и `vk.com`.
- Рейтинг в JSON-LD (`aggregateRating`) берётся из 2ГИС; если синхронизация ещё
  не проходила — из `data/site.ts`.

| `lib/social/*` | Адаптеры площадок, хранилище, планировщик синхронизации |

**Новая услуга** — один объект в `data/services.ts`. Карточка, фильтр, поиск,
прайс-лист, корзина и визард записи подхватят её автоматически. `image: null`
означает локальный градиент-плейсхолдер; положите фото в `public/images/services/`
и укажите путь.

**Новый мастер** — объект в `data/masters.ts`. `workDays`: 1 = понедельник,
7 = воскресенье. Слоты считаются по графику каждого мастера.

## Как работает запись

- Часовой пояс — Тюмень (UTC+5), без перехода на летнее время.
- Рабочий день 10:00–21:00, шаг слотов 30 минут, последняя запись должна
  закончиться не позже 21:00.
- На сегодня нельзя записаться раньше чем через 60 минут.
- Горизонт записи — 30 дней.
- Длительность заявки = сумма длительностей выбранных услуг (до 4 услуг).
- Пересечения проверяются на сервере в транзакции: два человека не займут
  одного мастера на одно время. Дубликат запроса (двойной клик) возвращает
  существующую заявку, а не создаёт вторую.
- Отмена — не позднее чем за 2 часа, по номеру телефона, на который оформлена
  запись, на странице `/my`.
- «Любой свободный» — сервер сам выбирает мастера, у которого слот свободен.

## API

| Метод | Путь | Назначение |
| --- | --- | --- |
| `GET` | `/api/slots?masterId=any&date=YYYY-MM-DD&duration=60` | Свободные слоты + ближайшие варианты |
| `POST` | `/api/bookings` | Создать заявку |
| `GET` | `/api/bookings?phone=+79123980880` | Заявки по телефону |
| `POST` | `/api/bookings/:publicId/cancel` | Отменить заявку (нужен телефон) |
| `POST` | `/api/feedback` | Пожелание/отзыв с сайта в Telegram |
| `POST` | `/api/sync` | Обновить данные 2ГИС, Яндекс Карт и VK |
| `GET` | `/api/sync` | Состояние последней синхронизации |
| `GET` | `/api/reviews?limit=40` | Отзывы площадок для модального окна |
| `GET` | `/api/vk-image?u=…` | Картинки постов VK через прокси (Referer + кэш) |

Тело создания заявки:

```json
{
  "name": "Иван",
  "phone": "+7 912 000-00-00",
  "comment": "Первый раз",
  "consent": true,
  "masterId": "alexander",
  "serviceIds": ["mens-cut", "beard-shape"],
  "startsAt": "2026-10-22T05:00:00.000Z",
  "requestKey": "случайная-строка-8-64-символа",
  "company": ""
}
```

`company` — honeypot: люди его не видят, боты заполняют. `requestKey` защищает
от двойной отправки. Все проверки дублируются на сервере.

## База данных

`data/mafia.db` (SQLite, WAL). Таблицы:

- `bookings` — заявки: имя, телефон, мастер, UTC-время начала/окончания,
  снимок услуг (JSON: название и цена на момент записи), сумма, статус.
- `services` — снимок каталога (id, название, категория, цена, длительность).
- `masters` — снимок мастеров и графика.
- `feedback` — сообщения из формы отзыва.
- `social_reviews`, `social_posts` — отзывы и посты площадок (id вида `2gis:…`).
- `social_stats` — рейтинг, число отзывов, подписчики по каждой площадке.
- `social_sync` — когда и с каким результатом проходила синхронизация.

Снимок услуг в заявке хранится отдельно: если завтра цена изменится, старые
заявки не «перепишутся».

Бэкап:

```bash
sqlite3 data/mafia.db ".backup 'backup-$(date +%F).db'"
```

## Деплой (кратко)

1. Node.js 22.5+ на сервере, `npm ci && npm run build`.
2. `.env.local` с токеном бота и `NEXT_PUBLIC_SITE_URL`.
3. `pm2 start npm --name mafia -- run start` (или systemd).
4. Nginx проксирует `127.0.0.1:3000`, Certbot — HTTPS.
5. Папка `data/` — на постоянном диске, включена в бэкап.
6. `NEXT_PUBLIC_SITE_URL` должен совпадать с реальным доменом, иначе canonical
   и OG-картинка будут указывать не туда.
7. Синхронизация: задайте `SYNC_TOKEN` и `MAFIA_SITE_URL` (адрес сайта), затем
   `npm run sync:install` — задача планировщика обновляет данные каждые 3 часа.
   На Linux/cron: `*/3 * * * * curl -fsS -X POST -H "x-sync-token: $SYNC_TOKEN" http://127.0.0.1:3000/api/sync`.

## Ограничения

- Приложение для App Store/Google Play не делалось — только два баннера-заглушки,
  как в задании.
- Отзывы и посты приходят с площадок автоматически, но через публичные
  (неофициальные) endpoint'ы: у 2ГИС нет открытого API отзывов, Яндекс отдаёт
  данные только в HTML карточки. Если площадка сменит формат или покажет капчу,
  синхронизация запишет ошибку, а на сайте останутся прошлые данные. Официальный
  путь для VK — сервисный ключ (`VK_TOKEN`).
- Выдуманных отзывов, акций и цифр на сайте нет: всё, что показано, взято с
  карточек организации или из группы VK.
- Уведомления в Telegram зависят от внешнего API. Если Telegram недоступен,
  заявка всё равно сохраняется, а ошибка логируется.
